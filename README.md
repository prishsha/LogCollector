# 🚀 Distributed Event Stream Analysis — E-Commerce Monitor

A distributed log collection and monitoring system built entirely using core Java (no frameworks, no dependencies).

## Overview
- Language: Java (JDK 11+)
- Dashboard: http://localhost:8080
- TCP Port: 9000

## Quick Start
```
javac *.java
java MainServer
```

Open http://localhost:8080

## Features
- Real-time log streaming
- Failure detection
- Live dashboard
